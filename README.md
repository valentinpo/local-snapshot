# 📦 local-snapshot — Project Backup Script

Лёгкий и надёжный скрипт для быстрого создания резервных копий проекта. Архивирует файлы в ZIP, проверяет место на диске, ведёт логи и выводит системные уведомления.

## ✨ Возможности
- 🗂️ Создает timestamped ZIP-архив в папке `backup/`
- 🚫 Автоматически исключает служебные папки (`.git`, `node_modules`, `venv`, `__pycache__` и др.)
- 💾 Проверяет свободное место перед запуском (требует минимум 120% от реального размера проекта)
- 🧪 Режим `--dry-run` для безопасного тестирования без создания файлов
- 📝 Подробное логирование всех действий в `backup/backup.log`
- 🔔 Всплывающее Windows-уведомление о результате (успех/ошибка)
- ⚡ Работает **только на стандартной библиотеке Python** (`pip install` не требуется)

## 🛠 Требования
- Python 3.6+
- ОС: Windows (для `.bat` и уведомлений). На Linux/macOS скрипт работает в терминале, уведомления автоматически игнорируются.

## 🚀 Установка и запуск
1. Поместите `backup.py` в **корневую папку проекта**.
2. Запустите любым удобным способом:

| Способ | Команда / Действие |
|--------|-------------------|
| 💻 Терминал | `python backup.py` |
| 🧪 Тестовый режим | `python backup.py --dry-run` или `python backup.py -d` |

## 📂 Структура после запуска
```
project/
├── src/
├── backup/
│   ├── backup.log
│   └── backup_2026-04-02_15-30-45.zip
└── backup.py
```


## ⚙️ Настройка
Чтобы изменить список исключаемых файлов/папок, откройте `backup.py` и отредактируйте список `IGNORE_PATTERNS` в начале файла:
```python
IGNORE_PATTERNS = ["backup", "__pycache__", ".git", ".idea", "venv", "node_modules", "dist", "build", "*.pyc", "*.pyo"]

🛡️ Скрипт предназначен для локальных ручных бэкапов. Он не заменяет систему контроля версий (Git), а дополняет её для быстрого отката рабочих состояний или архивации перед крупными правками.
